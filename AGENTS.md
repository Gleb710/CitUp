# Правила проекта
1. Вся логика игры живёт в Sim/ и не зависит от Godot (никаких using Godot). citup/ только рисует и принимает ввод.
2. Все действия игрока выполняются только командами (класс-команда, проверка и применение на тике).
3. Симуляция идёт 10 тиков в секунду; время считается в тиках, не в кадрах.
4. Данные (здания, рецепты, ресурсы) лежат в Data/*.json, числа в коде не зашиваются.
5. Маленькие шаги: одна функция или один экран за раз, после рабочего шага коммит. Для логики Sim нужен тест в Tests/.
6. Имя файла C# совпадает с именем класса; не называть скрипты именами встроенных типов Godot (Node2D, Sprite2D и т.п.).
