# CitUp

CitUp — прототип градостроительной игры с изометрической картой. Поддерживаются одиночная игра и многопользовательский режим по сети: один игрок создаёт игру и выступает хостом, остальные подключаются к нему.

## Требования

Для сборки и запуска из исходного кода необходимы:

- Windows.
- [Godot Engine 4.7.2 .NET](https://godotengine.org/download/) — именно .NET-версия редактора.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
- Git и Git LFS.

## Получение проекта

Клонируйте репозиторий:

```bash
git lfs install
git clone https://github.com/Gleb710/CitUp.git
cd CitUp
```

Если репозиторий уже клонирован без загрузки LFS-файлов, выполните:

```bash
git lfs pull
```

## Сборка и запуск

### Запуск через Godot

1. Откройте Godot Engine 4.7.2 .NET.
2. Импортируйте проект, указав файл `citup/project.godot`.
3. Дождитесь завершения импорта и сборки C#-скриптов.
4. Запустите проект клавишей **F5**.

### Запуск тестов

Из корневой папки репозитория выполните:

```bash
dotnet test Tests/Tests.csproj
```

Тесты проверяют логику симуляции, находящуюся в `Sim/`, независимо от Godot.

## Управление

- **WASD** или **стрелки** — перемещение камеры.
- **Колесо мыши** — изменение масштаба карты.
- **1, 2, 3** — выбор типа здания.
- **Левая кнопка мыши** — попытка построить выбранное здание в выбранной клетке.

Доступные действия и состояние игры зависят от выбранного режима.

## Режимы игры

После запуска открывается стартовое меню. В нём доступны три варианта.

### Одиночная игра

Нажмите **«Играть одному»**. Мир создаётся локально, симуляция выполняется на этом компьютере.

### Создание сетевой игры

1. Укажите имя игрока.
2. Оставьте порт `7777` или задайте другой свободный порт в диапазоне от `1024` до `65535`.
3. Нажмите **«Создать игру (хост)»**.
4. Передайте другим игрокам сетевой адрес хоста и порт.

Хост запускает симуляцию и является авторитетной стороной игровой сессии.

### Подключение к игре

1. Укажите имя игрока.
2. В поле **«Адрес хоста»** введите IP-адрес компьютера, на котором создана игра.
3. Укажите тот же порт, который использует хост.
4. Нажмите **«Подключиться»**.

После успешного подключения клиент получает состояние мира от хоста.

## Подключение через Radmin VPN

Для сетевой игры через Radmin VPN:

1. Все участники устанавливают и запускают Radmin VPN.
2. Участники подключаются к одной и той же VPN-сети.
3. Хост создаёт игру в CitUp.
4. Клиенты вводят VPN-адрес хоста (обычно адрес вида `26.x.x.x`) и порт игры.
5. Убедитесь, что брандмауэр Windows разрешает входящие UDP-подключения на используемый порт. По умолчанию это **UDP 7777**.

Для локальной проверки на одном компьютере можно использовать адрес `127.0.0.1`.

## Архитектура проекта

Репозиторий разделён на несколько основных частей:

- `Sim/` — игровая симуляция и правила игры. Не зависит от Godot.
- `citup/` — Godot-проект: отображение мира, пользовательский ввод, меню и сетевой транспорт.
- `Data/` — конфигурационные JSON-файлы и игровые решения.
- `Tests/` — автоматические тесты симуляции.
- `.github/workflows/` — сценарии автоматической сборки.

В многопользовательском режиме используется модель с авторитетным хостом:

- Хост выполняет игровую симуляцию.
- Клиенты отправляют хосту игровые команды.
- Хост проверяет команды и рассылает результаты участникам.
- Сетевые сообщения описаны в `Sim/Net/`, а передача данных через ENet реализована в `citup/NetManager.cs`.

Симуляция выполняется с частотой **10 тиков в секунду**. Игровая логика отделена от визуального представления, поэтому её можно тестировать без запуска Godot.

## Непрерывная интеграция и релизы

В репозитории настроен GitHub Actions workflow:

`.github/workflows/release.yml`

Workflow можно запустить вручную через вкладку **Actions** на GitHub. В этом случае выполняются тесты, экспорт Windows-сборки и загрузка ZIP-архива в артефакты запуска.

При отправке Git-тега, имя которого начинается с `v`, workflow дополнительно публикует GitHub Release с архивом Windows-сборки.

## Журнал игры

Игровой журнал ведётся отдельно для текущего режима игры. Для открытия папки с журналами нажмите **F4** во время работы приложения.
