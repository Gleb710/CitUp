# Решения по балансу MVP (числа можно менять, они настраиваются в JSON)

| Вопрос | Решение |
| --- | --- |
| Стартовые ресурсы | 1000 денег, 50 древесины |
| Дороги | в MVP нет, жители идут по свободным клеткам |
| Вместимость дома | 4 жителя (2 семьи, в каждой 1 работник) |
| Потребление жителя | 1 вода и 1 рыба в минуту |
| Налог | 0-50 денег с жителя за 60 с при ставке 0-100% |
| Работники на здание | 2 |
| Смена | 3 цикла рецепта для производства, до 10 единиц для носильщика |
